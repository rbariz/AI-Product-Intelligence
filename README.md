# AI Product Intelligence

> Comprendre un produit avant de construire son logiciel.

## Vision

AI Product Intelligence est un projet de recherche visant à concevoir une nouvelle manière d'imaginer les produits numériques.

Au lieu de générer directement une architecture à partir d'un prompt, la plateforme construit progressivement un **Modèle de Connaissance Produit** représentant le métier, les acteurs, les règles, les contraintes et les décisions.

L'architecture n'est pas un point de départ.

Elle est une conséquence de la compréhension.

## État du projet

🚧 Phase actuelle : Recherche & Conception

Le projet commence par la définition de ses fondations conceptuelles avant toute implémentation technique.
