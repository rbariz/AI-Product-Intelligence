## Vision

AI Product Intelligence est un projet de recherche consacré à la compréhension intelligente des produits numériques.

Plutôt que de générer directement une architecture à partir d'un prompt, la plateforme construit progressivement une représentation structurée du produit.

Cette représentation repose sur :

- un Product Knowledge Model ;
- une ontologie métier ;
- un Graphe de Connaissances ;
- plusieurs moteurs de raisonnement ;
- un ADN Produit calculé automatiquement.

L'objectif n'est pas de produire une architecture.

L'objectif est de comprendre le produit suffisamment bien pour recommander des architectures cohérentes, explicables et adaptées à son contexte.

L'architecture est une conséquence de la compréhension.
